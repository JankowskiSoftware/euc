# Build and deploy

    npm run build      # -> dist/euc-dashboard.html (single file) and dist/pwa/

`build.mjs` inlines CSS, vendored libs, an esbuild IIFE bundle of `src/main.mjs` and the gzipped+base64
sample (`data/sample.csv`) into one HTML file. It works from `file://` and fully offline (only OSM map tiles
need network, optionally).

## PWA (`dist/pwa/`)
Files: `index.html`, `manifest.webmanifest`, `sw.js` (cache name carries a content hash), PNG icons
(generated by `src/pwa/icons.mjs`, no external tools). The service worker precaches the shell (cache-first),
passes OSM tiles through network-first with a ~150-entry runtime cache.

Share target: after install, "EUC" appears in Android's Share sheet for CSV files. Android POSTs
multipart/form-data to `./share-target`; the SW stores the file in cache `euc-shared` (`shared/latest`, filename
in `x-filename`) and answers 303 to `./?shared=1`. The page then waits for `euc-ready`, reads the cached file,
calls `window.eucApp.loadFile(...)`, deletes the entry and cleans the URL.

Service workers, installation and share target require HTTPS (or localhost). Local test:
`npx http-server -p 8084 -c-1 dist/pwa`.

The PWA ships without the embedded sample ride, because it is meant for public hosting and the sample holds
a real GPS track; the "Przykład" button is hidden there. The single file keeps the sample.

## GitHub Pages
`.github/workflows/pages.yml` runs the tests, builds, and deploys `dist/pwa` on every push to `main` or the current working branch (or on a
manual run). One-time setup in the repository: Settings → Pages → Source: "GitHub Actions". A Pages site is
public even when the repository is private, and Pages on a private repository needs a paid GitHub plan.
After the first deploy, open `https://jankowskisoftware.github.io/euc/` in Chrome on Android, choose
"Zainstaluj aplikację" from the menu, and the app then appears in the Android share sheet for CSV files.

## Single file on Android
Copy `euc-dashboard.html` to the phone and open it from a file manager with Chrome, or enter
`file:///sdcard/Download/euc-dashboard.html` in Chrome. Limitations: opening via `content://` (some file
managers/Drive) may be blocked or open read-only in another app; no service worker, install or share target on
`file://`; Chrome may need the "Allow access to files" permission. Use the file picker inside the app to load CSVs.
